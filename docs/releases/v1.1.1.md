This release fixes the release workflow and removes committed Node modules from the Node SDK. Operators who build or publish Hayat from the repository, and developers working with the Node SDK, are the ones affected.

## Highlights

### Release workflow fix
The release workflow has been corrected so the release process runs as intended. This matters if you build or publish Hayat from the repository rather than consuming a prebuilt image.

### Node SDK cleanup
The Node SDK no longer carries a committed `node_modules` directory; it is now ignored via `.gitignore`. Developers working with the SDK should install dependencies themselves rather than relying on checked-in packages.

### Fixes and polish
- Release notes script in `.github/scripts/release-notes.mjs` updated.
- Docker release workflow adjusted.

No action needed.
